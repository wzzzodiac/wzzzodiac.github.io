# Visual Playground

Six designs, one catalogue. Open `index.html` through a local HTTP server, or visit https://wzzzodiac.github.io/visual-playground/.

| Design | Interaction |
| --- | --- |
| Sunday | Three Lisbon photo stories and a short walking prompt. |
| Out of Service | Three original SVG devices, power states and an exploded view. |
| Crumb | A six-piece pastry tray with a local 1200 x 1000 PNG export. |
| Last Transmission | A short fictional signal-recovery story with two endings. |
| Multiverse | The retained cat photo wall and viewer. |
| CASI | The retained chair experiment and poster export. |

Each design links back to this catalogue. No internal style selectors. The four new designs have a shared optional motion preference and honor reduced motion. Crumb and the story reset when reloaded.

## Sources

Credits are available inside each design. Sunday uses locally stored Unsplash photos by Aayush Gupta and Aleksandr Zaitsev under the Unsplash License. Crumb uses three original imagegen assets, with prompts in `miga/assets/generation-prompts.json`. Out of Service uses original inline SVG drawings. Last Transmission adapts Dimension's hub-and-window composition by HTML5 UP / AJ, retaining the CC BY 3.0 license at `../cats/templates/dimension/LICENSE.txt`. Local font licenses remain in `../cats/templates/fonts/`.

Visual references observed on 2026-11-08: Cereal / Rich Stapleton and Studio Faculty, Teenage Engineering, Pasticceria Adami / ET Studio, and HTML5 UP Dimension. Their proprietary artwork, photography, logos and text were not reused. The new code and copy were written for these designs.

The existing Multiverse artwork, behavior and licenses are preserved. CASI's publication copy now has concise English copy. The original local Playground 005 deliverable is unchanged. Old Editorial, Hub, Pastel Pink and Dimension addresses route to the corresponding new designs. Earlier cat studies remain archived outside the catalogue, with their sources and licenses retained in `../cats/`.

The Hub cover remains the original printmaking illustration generated with imagegen for Visual Playground. Catalogue thumbnails are actual browser captures of these designs.
