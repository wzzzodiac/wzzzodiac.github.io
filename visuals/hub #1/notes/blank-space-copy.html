NOTE 019 // WINDOWS / UTILITY

Blank space copy

A one-click invisible character for folder names, labels or anywhere a normal space is not visually enough.

Important

This does not copy an actually empty string. It copies an invisible Unicode character: U+2800 BRAILLE PATTERN BLANK. It looks blank, but software still sees it as a real character.

Character: U+2800 // visually blank but not empty
01

Copy it

Press COPY BLANK SPACE. The invisible character is placed in the clipboard.

02

Paste it where needed

Paste normally with Ctrl + V. It can be useful when you want something to look unnamed while still containing a valid character.

03

If one blank is already used

Copy the character twice or combine several copies. Windows may require a different filename if another item in the same location already uses the exact same invisible name.

Short version

  • Click the copy button.
  • Paste with Ctrl + V.
  • If the name already exists, paste the blank character more than once.
