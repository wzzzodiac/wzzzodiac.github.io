NOTE 003 // INSTAGRAM / BROWSER CONSOLE

Instagram follower filtering utility

A quick reference for the browser-console workflow I use to inspect follower relationships and work with the resulting account list.

Use on your own account / use at your own risk

This note does not run the script automatically. The code only executes after you deliberately paste it into Instagram's developer console. It works with data available to your logged-in session and the utility also contains an unfollow action. Instagram can change its internal endpoints or rate limits at any time, so there is no guarantee it will always work and temporary blocks are possible. I keep this here because it is the workflow I use; each person is responsible for what they run and which accounts they modify.

01

Open your Instagram profile

Log in normally and go to Instagram → Profile. The script is intended to be run while you are already inside Instagram with your own session.

02

Open the browser console

Right-click the page → Inspect / Inspect element, then open the Console tab.

03

Paste the script and press Enter

Open the code box below, copy the full script, paste it into the console and press Enter.
