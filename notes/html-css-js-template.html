NOTE 012 // HTML / CSS / JS

Small HTML/CSS/JS project template

The minimal structure behind most of the tiny web experiments in the hub.

01

Keep the root simple

project/
├── index.html
├── style.css
└── script.js

index.html defines structure, style.css presentation and script.js behavior.

02

HTML connects the files

<link rel="stylesheet" href="style.css">
...
<script src="script.js"></script>

Use relative paths so the same project works locally and on GitHub Pages.

03

Give interactive elements IDs/classes

HTML should expose stable hooks for JavaScript and CSS. Avoid making behavior depend on fragile visual positions in the page.

04

JavaScript starts after the DOM exists

Placing the script near the end of body is a simple way to ensure the elements already exist before listeners are attached.

05

Test locally first

Open the page locally for basic static projects. If browser security, modules or fetch requests are involved, use a small local web server instead of assuming a GitHub Pages problem.

06

Publish only after the local state is clean

Check paths, browser console errors, mobile layout and reset/retry behavior before publishing. A three-file project can still have surprisingly creative failure modes XD.
