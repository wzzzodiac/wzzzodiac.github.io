NOTE 010 // VS CODE / TERMINAL

VS Code / terminal basics

The handful of actions needed to open a project, inspect files and run commands without turning the editor into its own hobby.

01

Open the project folder

code <folder>

Opening the folder instead of individual files gives the terminal and editor the correct project context.

02

Integrated terminal

Use Terminal → New Terminal. Check the current directory before running build, Git or package commands.

pwd
ls

pwd shows where the terminal currently is. ls shows the directory contents.

03

Find things quickly

Use the file search for filenames and the workspace search for text/functions. Search before manually opening twenty files.

04

Format deliberately

Use Format Document after the code is correct. Formatting should make structure easier to read, not be mixed with functional changes when debugging.

05

Useful extensions only

Install language support and tooling actually used by the project. Avoid installing a giant extension pack unless its features are genuinely needed.

06

Before closing

Save files, inspect git diff, compile/run the relevant test, then commit only after the change has been checked.
