NOTE 007 // WINDOWS

Fresh Windows setup checklist

The order I want after reinstalling Windows: drivers, security, startup, essentials, then optional tools.

01

Windows Update first

Install normal system updates and restart before piling third-party utilities on top.

02

Drivers

Install GPU and important device drivers. For driver discovery, prefer Snappy Driver Installer over random “optimizer” suites; inspect what it proposes instead of blindly installing everything.

03

Security baseline

Use Windows Defender and SmartScreen as the permanent baseline. Keep Malwarebytes as an occasional second-opinion scan and AdwCleaner only for suspicious browser/adware behavior.

04

Browser

Install the browser, password/account sync if wanted, and uBlock Origin for unwanted redirects and page clutter.

05

Startup apps

Open Task Manager → Startup apps and leave enabled only what should genuinely launch with Windows.

06

Useful tools

Add only the tools actually used: PowerToys, development tools, hardware utilities, Office, communication apps and project software. Avoid rebuilding years of accumulated junk in one afternoon.

07

Final cleanup

Review installed apps once everything works and remove installers, trial utilities and software that turned out unnecessary.
