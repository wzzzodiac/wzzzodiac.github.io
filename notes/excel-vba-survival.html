NOTE 011 // EXCEL / VBA

Excel / VBA survival notes

The small set of concepts that turned Excel from a spreadsheet into something programmable.

01

Open the VBA editor

Enable the Developer tab when needed, then open Visual Basic. Macros normally live inside modules instead of being pasted randomly into worksheet code.

02

Basic macro shape

Sub MyMacro()
    ' actions
End Sub

Sub starts a macro and End Sub closes it. Give each macro one clear job.

03

Target a sheet and range

With Sheets("SheetName").Range("B6")
    ' properties
End With

With lets several operations target the same object without repeating its full address.

04

Common properties

.Value changes content. .Font controls font properties. .Interior controls cell fill. .HorizontalAlignment controls alignment. These are object properties, not magic Excel keywords.

05

Buttons

A worksheet button can be assigned to a macro. Keep the button simple and let the macro contain the logic so the worksheet stays understandable.

06

Debugging

If a macro fails, identify the exact line, check the sheet/range name and inspect values before making the code more complicated. Most beginner errors are object names, ranges or assumptions about what is currently selected.

Rule

Prefer explicit sheet/range references over relying on ActiveSheet or Selection when the macro should behave predictably.
