NOTE 014 // UBUNTU / DEBUG

Ubuntu emergency commands

Commands that actually appeared while debugging the Raspberry/LiDAR system, ordered from “is the machine connected?” to “is the container alive?”.

01

Interfaces and IP addresses

ip -brief address

Shows whether interfaces are up and which addresses they currently have. This was the first useful check when the LiDAR stopped being reachable after reboots.

02

NetworkManager connections

nmcli connection show

Lists configured and active NetworkManager connections. Useful for confirming that the intended static Ethernet profile exists.

03

Reachability

ping -c 4 <IP>

Sends four ICMP checks. If the sensor cannot be reached here, ROS and RViz are not the next problem yet.

04

Containers

docker ps
docker compose up -d

docker ps shows running containers. docker compose up -d starts the configured stack in the background.

05

Inspect Docker networking / IPC

docker inspect <container> \
  --format 'STATUS={{.State.Status}} IPC={{.HostConfig.IpcMode}} NETWORK={{.HostConfig.NetworkMode}}'

This became important when DDS discovered topics but RViz still received no cloud. It confirms whether the container is running with the intended IPC and network modes.

06

Open the workspace in VS Code

code ~/ros2_docker_ws

Opens the real workspace root, avoiding edits in random copies of files.

Debugging rule

Start low in the stack: physical connection → IP → container → ROS graph → messages → visualization.
