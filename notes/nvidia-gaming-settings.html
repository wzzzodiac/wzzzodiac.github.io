NOTE 009 // NVIDIA / DISPLAY

NVIDIA gaming settings

The small set of display and latency settings worth checking after a driver reinstall or monitor change.

01

Resolution and refresh rate

Confirm the monitor is running at its native resolution and intended high refresh rate. Windows and NVIDIA settings can silently fall back to a lower refresh rate after hardware or driver changes.

02

G-SYNC / adaptive sync

If the monitor supports it, verify G-SYNC or compatible adaptive sync is enabled for the intended display mode. Also confirm the monitor itself has adaptive sync enabled where required.

03

Low-latency behavior

Use the low-latency option deliberately rather than changing every global 3D setting. If a game provides NVIDIA Reflex, prefer the game's own supported latency control.

04

Frame-rate cap

Only apply a cap when it serves a purpose: staying inside the adaptive-sync range, stabilizing frametimes or reducing unnecessary GPU load. Do not cap globally just because a guide said so.

05

Per-game settings

Keep global settings conservative. Make unusual overrides per game so one experiment does not quietly affect every application.

After every driver reinstall

  • Native resolution.
  • Correct refresh rate.
  • Adaptive sync / G-SYNC.
  • Latency option if needed.
  • Any intentional per-game overrides.
