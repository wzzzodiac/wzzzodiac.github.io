NOTE 001 // GITHUB

Publish a small project with GitHub Pages

A reusable checklist for taking a simple HTML/CSS/JavaScript project from a local folder to a public URL.

Starting point

Your project already contains index.html, style.css and script.js.

01

Create the repository

In GitHub, create a new repository and give it the project name, for example financial-damage-calculator.

Do not create another repository named username.github.io. That name belongs to the main hub.

02

Upload the project files

Inside the new repository use Add file → Upload files and upload the project files.

index.html
style.css
script.js

The important part is that index.html sits directly in the repository root, not inside another project folder. Commit the upload.

03

Enable GitHub Pages

Open Settings → Pages. Under Build and deployment choose:

Source: Deploy from a branch
Branch: main
Folder: / (root)

Save the configuration.

04

Wait for publication

Give GitHub one or several minutes, then return to Settings → Pages. The public address normally follows this pattern:

https://YOUR-USER.github.io/REPOSITORY-NAME/

Example:

https://wzzzodiac.github.io/financial-damage-calculator/
05

Remember: repository and website are different

Repository:
https://github.com/YOUR-USER/REPOSITORY-NAME

Published website:
https://YOUR-USER.github.io/REPOSITORY-NAME/
06

Add it to the main hub

Open the main YOUR-USER.github.io repository, edit the project index in the hub, add the new project and commit the change.

07

Recommended structure

YOUR-USER.github.io  → main hub
project-1            → separate repo + GitHub Pages
project-2            → separate repo + GitHub Pages
project-3            → separate repo + GitHub Pages

Each project owns its repository and URL. The hub simply links everything together.

Quick checklist

  • Create repo with the project name.
  • Upload index.html, style.css and script.js to the root.
  • Commit.
  • Settings → Pages.
  • Deploy from a branch → main → / (root).
  • Save and wait for publication.
  • Test the public URL.
  • Add the project link to the main hub and commit again.
