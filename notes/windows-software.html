NOTE 002 // WINDOWS

Windows software setup

A short personal reference for the utilities and security setup worth remembering when cleaning or rebuilding the PC.

01

Drivers: Snappy instead of Driver Booster

Use Snappy instead of Driver Booster. The interface looks old, but it is fast and useful.

02

Check startup apps

Open Task Manager → Autostart. Keep enabled only the applications that should actually launch with Windows.

03

Security after Kaspersky

When Kaspersky Premium expires, use Windows Defender with SmartScreen enabled.

Use Malwarebytes from time to time as an additional scan. The note assumes normal browsing habits rather than constantly visiting suspicious sites.

04

Browser protection

Use uBlock Origin to reduce redirects and unwanted page behavior on sites that are heavy on advertising or redirects.

05

AdwCleaner: only when something looks wrong

Keep AdwCleaner as a troubleshooting tool. Use it when something strange happens, and much less often than Malwarebytes.

06

Remove unused apps

Occasionally review installed applications and uninstall software that is no longer used.

Quick rebuild checklist

  • Snappy for driver work.
  • Task Manager → Autostart: keep only wanted startup apps.
  • Windows Defender + SmartScreen after Kaspersky expires.
  • Malwarebytes occasionally.
  • uBlock Origin in the browser.
  • AdwCleaner only when something unusual happens.
  • Review and remove unused applications.
