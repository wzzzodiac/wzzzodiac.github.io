NOTE 008 // PC / HARDWARE

GPU / PC sanity check

A short checklist after changing hardware or reinstalling drivers. The goal is not chasing benchmark records; it is confirming that the machine behaves normally.

01

Check detection

Confirm that Windows and the NVIDIA driver identify the intended GPU, monitor and refresh rate. Check Device Manager only for unresolved devices or warning icons.

02

RAM / XMP

Confirm the memory is running at the intended profile instead of a lower default speed. Remember that DDR tools may report half the effective DDR rate.

03

Temperatures and clocks

During load, watch GPU/CPU temperature, clock behavior and whether performance suddenly collapses. The useful question is whether the system stays stable, not whether a sensor briefly touches a specific number.

04

Stress / benchmark

Use a controlled tool such as OCCT or 3DMark to check for crashes, artifacts, driver resets or obvious instability. Stop if the behavior is abnormal.

05

Power and cabling

Verify PCIe power connectors and that the GPU is seated correctly. Hardware instability after a change is often simpler than software makes it look.

06

Real game test

Finish with an actual game or workload. Synthetic stability is useful, but the final check is whether the PC behaves normally in the applications it was built to run.
